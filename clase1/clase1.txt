Comentarios en SQL 

Opcion 1: Para comentarios de una linea, se utilizan dos guiones y un espacio.

    Ejemplo : 
    -- Esta linea es un comentario 
    --Esta linea NO es un comentario

Opcion 2: Comentariosde multiples lineas /* */

    Ejemplo :
        /*
        Este es un comentario
        de multiples lineas
        */

Es importante usar comentarios para explicar el codigo, especialmente cuando el proposito del codigo no es inmediantemente obvio, o para explicar el
"Por que" detras de ciertas decisiones de diseño.

-- USE en SQL

El comando USE se utiliza para seleccionar la base de datos

Ejemplo: USE empresa;

-- DROP DATABASE en SQL

El comando DROP DATABASE sirve para eliminar una base de datos. 

Ejemplo: DROP DATABASE (database);

-- Tipos de Datos en SQL
En SQL, los tipos de datos se clasifican en varias categorias, segun el tipo de valor que almacenan. 

Tipo; TINYINT       Tamaño; 1 byte       Descripcion; Entero muy pequeño (-128 a 127)
Tipo; SMALLINT      Tamaño; 2 byte       Descripcion; Entero pequeño
Tipo; MEDIUMUT      Tamaño; 3 byte       Descripcion; Entero Mediano 
Tipo; INT O INTEGER Tamaño; 4 byte       Descripcion; Entero Estandar 
Tipo; BIGINT        Tamaño; 8 byte       Descripcion; Entero muy Grande
